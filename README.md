# Personage (RPG Character Editor)

Простое настольное приложение на C# (Windows Forms) для создания и управления персонажами и их оружием в RPG-играх.

## Что делает проект:
1. **Создает персонажей и оружие** — позволяет настраивать характеристики героев (сила, ловкость, интеллект, уровень), добавлять им уникальное оружие и загружать для всего этого картинки-аватарки.
2. **Объединяет (крафтит) оружие** — если выбрать два оружия одного типа, программа позволяет «сложить» их вместе для улучшения характеристик с помощью перегруженного оператора `+=`.
3. **Считает боевую мощь** — рассчитывает общую силу персонажа по специальной формуле на основе его характеристик и экипировки, после чего автоматически присваивает ему внутриигровое звание.

## Стек:
* C# / .NET 
* Windows Forms (GUI)
* Объектно-ориентированное программирование (ООП)
